# Yiying Garden Walk-Along Visualization

- Park: Yiying Garden (怡影园)
- Language: en
- Data: `data/`
- Model results: `results/`

## Folders

1. `01_network_scores/` — network + mid-segment Q scores
2. `02_recommended_paths/` — three gate→exit recommendations
3. `03_frame_walk/` — walk GIF; recommendations only on arrival (frames regenerated by build)
4. `04_midtrip_reroute/` — once / twice destination changes
5. `05_aimless_twostep/` — aimless two-step local options

Rebuild from the repo root with `python src/build.py`.
